## 💻 Local Setup

Clone and run locally using Python's built-in server:

```bash
git clone https://github.com/Althafk7171/portfolio.git
cd portfolio
python -m http.server 8080
```

Open your browser at `http://localhost:8080`.

---

## 🌐 Deploy to GitHub Pages

1. Go to your repository settings on GitHub: **Settings → Pages**.
2. Under **Branch**, select `main` and root folder `/`.
3. Click **Save**. Your site will be published at:
   `https://althafk7171.github.io/portfolio` (or `https://althafk7171.github.io` if named `althafk7171.github.io`).
